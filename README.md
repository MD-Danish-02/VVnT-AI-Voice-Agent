# VVnT AI Voice Agent

AI-powered voice calling agent platform for VVnT SeQuor.

## Project Overview

The VVnT AI Voice Agent is an AI-powered voice communication system designed to handle customer conversations, understand business requirements, qualify leads, answer VVnT-related questions, schedule meetings, and transfer complex conversations to human representatives.

## Core Capabilities

- AI-powered voice conversations
- Lead qualification
- Customer requirement analysis
- VVnT service and company knowledge
- RAG-based responses
- Lead management
- Appointment scheduling
- Human handoff
- Call transcripts
- Call summaries
- Lead scoring
- Admin dashboard
- Inbound and future outbound calling
